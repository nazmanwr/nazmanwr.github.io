The site lives on GitHub, so a change made here is saved straight into it and the live page follows about a minute later. That needs a token, made once and pasted here once per phone or iPad.

  1. On GitHub, open this pre-filled token page (name, one-year expiry and Contents: read and write are already set).
  2. Repository access: Only select repositories → nazmanwr.github.io.
  3. Check Permissions shows Contents: Read and write and nothing else.
  4. Press Generate token, copy it, and paste it below.
